# Таксі «Їдемо» — структурований JavaScript-проєкт

Це ES Modules проєкт на HTML/CSS/vanilla JavaScript із класами. Прототип збережено: інтерфейс, карта, сценарії замовлення, пошук водія, симуляція поїздки, історія, оплата та модальні вікна.

## Запуск

Потрібно відкривати через локальний HTTP-сервер, тому що браузер може блокувати імпорт ES-модулів при відкритті `file://`.

**Варіант 1 (без встановлення залежностей):**
```bash
cd yidemo_structured_project
python -m http.server 8000
```
Відкрити http://localhost:8000

**Варіант 2 (Vite):**
```bash
npm install
npm run dev
```
Відкрити URL, показаний у терміналі.

## Структура
- `index.html` — розмітка, не містить JS-логіки і CSS.
- `css/styles.css` — стилі, перенесені з прототипу.
- `js/main.js` — точка входу.
- `js/app/` — головний контролер і сценарії.
- `js/models/` — моделі сутностей: `Order`, `Driver`, `Passenger`, `Route`, `Tariff`, `Payment` тощо.
- `js/services/` — тарифи, пошук водіїв, замовлення, геокодування, історія та симуляція.
- `js/ui/` — карта, компоненти і допоміжні функції.
- `js/ui/screens/` — окремий клас для кожного екрана.
- `js/ui/modals/` — окремий клас для кожного діалогового вікна.
- `js/core/` — події, годинник, генератор псевдовипадкових чисел.
- `js/data/seed.js` — тестові дані для локальної демонстрації.
- `js/config.js` — конфігурація.

## Обмеження
Це фронтенд-симуляція, не справжній сервіс замовлення таксі. Водії, платежі й час поїздки моделюються, зовнішній сервер відсутній.
